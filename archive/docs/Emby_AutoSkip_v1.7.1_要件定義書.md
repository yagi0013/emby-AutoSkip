# Emby AutoSkip 要件定義書

**文書版 1.0  |  対象実装 v1.7.1  |  2026年10月10日**

> 本文書は現行ソースコードから逆算して整理した「現行仕様ベースの要件定義書」です。新規実装指示ではありません。要件・受入条件は設計上の整理であり、試験完了を保証しません。

## 1. 背景・目的・設計原則
**背景：** Emby Web Playerでは、作品によってイントロ・前回のあらすじ・OP・EDを毎回手動で飛ばす必要がある。視聴そのものが目的であり、補助ツールの操作に注意を奪われたくない。

**目的：** チャプター情報を活用して不要な区間の視聴操作を自動化しつつ、見たい場合には取消・手動操作・復帰ができる状態を作る。

**設計原則：** 「動画視聴のUXを改善すること」が目的。「見つけやすいが邪魔しないUI」「初回の視聴機会を確保」「誤動作から戻せること」を両立する。

## 2. 適用範囲と前提
**対象：** Emby Web Playerで再生される、Embyからチャプター／イントロマーカーを取得できる動画。ブラウザー内で動作するJavaScript。

**対象環境：** Ubuntu上のEmby Server 4.10.1.0（既知の運用環境）、Chrome／Brave等のWebブラウザー。サーバーのWeb UIからの読込を主方式、Tampermonkeyを代替方式とする。

**対象外：** Embyネイティブアプリ、動画ファイル自体の加工、音声・画像解析によるOP／EDの自動検出、チャプターの自動生成、クラウドへの設定同期、ユーザー間共有、Emby公式プラグイン化。

**前提：** Embyへのログイン済みWeb環境、APIにアクセスできる権限、認識可能な再生セッションおよびスキップ区間の根拠となるチャプター情報。

## 3. 機能要件
### FR-01 再生対象の認識
Webページの再生中動画を検出し、Emby APIの再生セッション／作品IDと対応付ける。作品が切り替わったら当該再生に限る判断状態を初期化する。
**受入条件：** 作品A→Bに切り替えるとBのチャプター・操作状態を扱い、Aのキャンセルは継続しない。

### FR-02 イントロ／あらすじ制御
「イントロ・前回のあらすじ」の自動スキップをON／OFFできる。
**受入条件：** ON時に有効な対象区間へ入るとジャンプし、OFF時は自動ジャンプしない。

### FR-03 OP／EDの3モード
OPとEDを別々に「常に再生」「初回のみ再生」「常にスキップ」に設定できる。
**受入条件：** OPとEDに異なるモードを設定しても互いに影響しない。

### FR-04 全体／シリーズ別設定
全体設定とシリーズ専用設定を切り替えられる。「全体設定を使用」のON時は全体値を採用し、OFF時は専用値を採用する。
**受入条件：** シリーズ設定をON→OFF→ON（全体設定使用の切替）しても個別設定値が保持される。

### FR-05 初回再生履歴
「初回のみ再生」ではSeriesId単位でOP／EDの履歴を独立管理する。終端到達または当該区間の手動スキップで視聴済みとし、以降は自動スキップする。
**受入条件：** 新しいシリーズでは初回再生、次話では自動スキップ。OP済・ED未などの別管理ができる。

### FR-06 初回履歴の表示・リセット
シリーズ設定画面にOP／EDの初回履歴を表示し、現在のシリーズの履歴を消去できる。
**受入条件：** リセット後、該当シリーズは再び初回扱いになる。

### FR-07 30秒前の予告
自動スキップ対象のイントロまたはOPの開始30秒前から残秒を表示する。表示機能は全体設定でON／OFFできる。EDは予告対象外。
**受入条件：** 開始30秒以内でIN／OPと残秒を表示し、予告OFF時は非表示。

### FR-08 事前キャンセル
予告中の「キャンセル」でその区間の自動スキップを当該作品再生中だけ取り消せる。
**受入条件：** 取消後に区間へ入ってもジャンプせず、別作品へ移動すると取消状態がクリアされる。

### FR-09 初回中の手動スキップ
初回のみ再生が有効で未視聴扱いのOP／ED区間では「スキップ」を表示し、その場で区間終端へジャンプできる。
**受入条件：** ボタン押下でジャンプし、シリーズの当該種別を初回視聴済みに記録する。

### FR-10 スキップ後の復帰
自動／手動スキップ後の約5秒間「↶ 戻す」を表示し、押下で区間開始位置へ戻れる。復帰した区間は同一再生中に再スキップしない。
**受入条件：** 5秒以内は復帰可能、時間経過で表示消失。復帰後に再度飛ばされない。

### FR-11 章情報から区間生成
Embyのチャプター名・マーカー種別・時間情報でイントロ／OP／ED区間を形成し、妥当な長さの区間のみ採用する。
**受入条件：** マーカーのある作品で対象区間を判定でき、区間不明の場合は自動ジャンプしない。

### FR-12 収納式設定UI
右端の細いタブからパネルを開閉し、タブを上下ドラッグで移動できる。動画がない場合はUIを隠す。画面高さが低い場合は内部スクロールする。
**受入条件：** パネルを開いて設定でき、ドラッグ位置が再訪時にも保持され、画面からはみ出さない。

### FR-13 設定の永続化と移行
全体値、シリーズ専用値、タブ位置、初回再生履歴をブラウザーのlocalStorageに保存し、既知の旧設定形式を読み込んで引き継ぐ。
**受入条件：** 再読み込み後も設定・履歴を利用でき、旧形式のOP／ED ON/OFFが新3モードへ変換される。

### FR-14 診断インターフェース
開発者ツールからバージョン確認・再生状態取得・区間一覧表示・再取得を実行できる。
**受入条件：** EmbyAutoSkip.version / status() / inspect() / retry() が利用できる。

## 4. UI / UX 要件
**UX-01 非侵襲性：** 再生が主役。通常は半透明・幅17pxの右端タブのみを表示し、ホバーまたは操作が必要なときに視認性を上げる。

**UX-02 操作の可逆性：** 事前キャンセル・事後の「戻す」の両方を提供する。スキップは強制ではなく、ユーザーの意思を優先する。

**UX-03 コンテキスト適応：** 自動スキップの前は残秒＋キャンセル、初回視聴中は手動スキップ、直後は復帰など、時間と状態に応じて操作を切り替える。

**UX-04 配置の自由度：** タブ位置は上下ドラッグで調整し保存する。パネルは画面内に収め、全画面表示中も原則利用可能とする。

**UX-05 設定の明確性：** 全体とこのシリーズの対象を表示し、シリーズの継承状態と初回履歴を確認できる。

## 5. 非機能要件
**NF-01 外部通信・機密性：** Emby APIへのアクセスにログイン済みブラウザー内の認証情報を利用する。ソースに固有トークンを埋め込まない。コード上、別ドメインへの収集・送信処理を必要としない。

**NF-02 障害時挙動：** 再生動画や認証情報、対象セッション、区間情報を取得できないときは勝手にスキップしない。診断状態・エラーを把握できる。

**NF-03 運用互換性：** Emby WebのJavaScriptとして動作し、ネイティブクライアントは対象としない。Emby更新でWeb UIファイルが置換される場合があるため、再適用可能な導入方法を維持する。

**NF-04 設定の保存範囲：** 設定・履歴は同じオリジンのブラウザー内に保持され、他ブラウザー・他端末へは同期しない。

**NF-05 資源利用：** 再生セッションの取得は約2.5秒周期、スキップ判定は約0.3秒周期。応答時間・CPU負荷の数値目標は未定義／未計測。

**NF-06 保守・切戻し：** 単独のJSファイルとWeb UIの読込タグで有効化し、両者のバックアップ・復旧ができる。旧版への切替・無効化手順を持つ。

## 6. インターフェースおよび設定保存
- **Emby Sessions API**（`GET /Sessions`）：ログインユーザーの再生中作品・セッション・PositionTicksを参照する。
- **Emby Items API**（`GET /Items?Ids={id}&Fields=Chapters`）：作品のチャプター／シリーズ情報を取得する。必要時は /Users/{userId}/Items/{id} を利用する。
- **認証情報**（`Emby Webのservercredentials3`）：利用中のEmby Webが持つトークンを読み取り、X-Emby-Tokenで同一オリジンへの要求に付与する。
- **再生シーク**（`HTMLVideoElement.currentTime`）：区間終端へのジャンプ、スキップ取り消し後の区間開始への復帰に利用する。

### 6.1 保存データ
- **全体設定**：`emby-autoskip-settings-v17` — intro/op/outro/countdown
- **シリーズ設定**：`emby-autoskip-series-settings-v17` — SeriesIdをキーとする個別設定／継承フラグ
- **初回履歴**：`emby-autoskip-first-play-history-v17` — SeriesIdごとのOP／ED初回完了状態
- **タブ位置**：`emby-autoskip-edge-position-v14` — ブラウザー内での縦位置比率
- **旧設定参照**：`emby-autoskip-settings-v13 / emby-autoskip-series-settings-v16` — 新規保存値がない場合の移行元

## 7. 制約・既知の留意点
**C-01 チャプター依存：** 区間認識はEmbyが提供する名前付きチャプター／IntroStart・IntroEndマーカーに依存する。マーカーがなければ自動検出はできない。

**C-02 判定の安全枠：** 現行コードの区間採用条件は長さ0.5秒超かつ360秒以下。名前付きチャプターの「次のチャプター」を終端とみなす補完は差分210秒以下。非EDは開始1200秒より後を原則対象外とする。

**C-03 初回の粒度：** 「初回」はSeriesId×OP/ED種別の単位。エピソード単位・シーズン単位・楽曲差替え単位ではない。

**C-04 初回判定の例外：** SeriesIdがない場合「初回のみ再生」は視聴済みを保存できず、毎回初回扱いで自動スキップしない。シークによる終端到達でも視聴済み判定が起き得る。

**C-05 復帰と履歴の非連動：** 初回中に手動「スキップ」すると履歴を視聴済みにする。直後に「戻す」で復帰しても、現行実装は履歴を自動で未視聴に戻さない。

**C-06 セッション選択：** 同一ユーザーが複数のWeb再生を同時に行うと、時刻差に基づくセッション選択が誤る可能性がある。

**C-07 導入方式の競合：** サーバー埋込とTampermonkeyの同時有効化、またはscriptタグの二重追加により処理が重複する可能性がある。

## 9. 未決事項・保証範囲
- **保留01**：UI操作のアクセシビリティ（キーボードのみ・スクリーンリーダー等）に対する正式な対応範囲は未確定。
- **保留02**：性能上限、CPU負荷、メモリ消費、APIリクエスト許容量の定量基準は未設定。
- **保留03**：将来のEmbyバージョン、Safari／Firefox、モバイルWebなどの互換保証範囲は未確定。
- **保留04**：複数同時セッションの厳密な判定、初回履歴の同期、OP曲変更の認識は現時点では対象外。
- **保留05**：仕様書中の受入条件は実装から抽出した検証観点であり、この文書の作成時点で全項目の実機試験完了を意味しない。

# Emby AutoSkip v1.11.2

Emby Web Player向けの非公式JavaScript拡張です。イントロ・OP・EDの自動スキップ、初回のみ再生、手動スキップと「戻す」に対応します。

同梱対象：本体 **v1.11.2**、任意追加の同期プラグイン **v1.0.5**。

## 変更内容

- 本体：疑似シークバーの区間表示を無効にした際に描画キャッシュを破棄し、再度有効にしたときに色表示が復元されるよう修正しました。
- 同期：既存の同期へ参加するときのJSON自動書き出しを廃止し、ブラウザー設定をクラウド設定で置き換える確認文へ変更しました。必要なバックアップは参加前に手動で書き出してください。

## 導入・更新

- 本体は `emby-autoskip.js` を使用してください。同期を利用する場合のみ `emby-autoskip-sync.js` も必要です。
- サーバー配信方式では既存のJSを置き換え、読込タグのキャッシュ識別子を本体 `?v=1.11.2`、同期 `?v=1.0.5` に変更し、ブラウザーを強制再読み込みしてください。
- サーバー配信方式とTampermonkeyを同時に有効にしないでください。

[導入・更新手順](https://github.com/yagi0013/emby-AutoSkip/blob/main/GUIDE.md) · [変更履歴](https://github.com/yagi0013/emby-AutoSkip/blob/main/CHANGELOG.md)

## 動作環境

動作確認済み：Ubuntu / Emby Server 4.10.1.0 / Chrome・Brave。Emby Web向けで、ネイティブアプリは対象外です。スキップ区間の検出にはEmbyのチャプター／イントロマーカーが必要です。

同期には別途HTTPSの対応APIが必要です。このリポジトリにAPIサーバー実装は含まれません。

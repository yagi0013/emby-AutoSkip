# Emby AutoSkip

Emby Web Playerで、イントロ・前回のあらすじ・OP・EDを自動スキップする非公式JavaScript拡張です。
Embyのチャプター／イントロマーカーを使い、作品ごとに「見る・飛ばす」を選べます。

**本体 v1.12.0** / 任意追加の同期プラグイン **v1.0.5**

[導入・使い方](GUIDE.md) · [変更履歴](CHANGELOG.md) · [リリース一覧](https://github.com/yagi0013/emby-AutoSkip/releases) · [不具合の報告](https://github.com/yagi0013/emby-AutoSkip/issues)

> Emby公式プラグイン（DLL）ではありません。Emby Web向けの拡張です。チャプター情報がない／誤っている作品は、正しくスキップできない場合があります。動画の音声解析機能はありません。

## できること

- **視聴スタイルに合わせる**：イントロのON/OFF、OP・EDの「常に再生」「初回のみ再生」「常にスキップ」。シーズン／シリーズごとの設定にも対応。
- **その場で操作する**：手動スキップ、今回だけキャンセル、スキップ直後の「戻す」、AutoSkipの一時停止。
- **一覧で対象を見つける**：サムネイル左下のⓈバッジでスキップ区間のある作品を表示。シリーズ・シーズンは説明に「全話Skip対象」「一部Skip対象」を表示し、探査と表示を設定でON／OFF。
- **区間を見ながら再生する**：シークバーの色分け、残秒表示、`Ctrl+←` / `Ctrl+→` のチャプター移動。
- **設定を持ち運ぶ**：JSONで書き出し・読み込み。対応APIを別途用意すれば、追加プラグインで暗号化同期も可能。

初期設定はイントロON、OPは「常にスキップ」、EDは「常に再生」です。「初回のみ再生」の履歴はシーズン単位（シーズン情報がない場合はシリーズ単位）で記録します。

## ダウンロードと導入

| ファイル | バージョン | 用途 |
| --- | --- | --- |
| [emby-autoskip.js](emby-autoskip.js) | 1.12.0 | 本体。通常はこちらだけで利用可能 |
| [emby-autoskip-sync.js](emby-autoskip-sync.js) | 1.0.5 | 任意追加の設定同期プラグイン |

各ファイルを開き、GitHubの **Raw** 表示から保存してください。ビルドは不要です。

1. **Embyサーバーから配信（推奨）**：Emby Webの配信フォルダーへJSを置き、`index.html` から読み込みます。[バックアップを含む導入手順](GUIDE.md#導入方法aembyサーバーから配信推奨)を参照してください。
2. **Tampermonkey（代替）**：サーバー側を編集できない場合は、UserScriptとして登録できます。[導入手順](GUIDE.md#導入方法btampermonkey代替)を参照してください。
3. 画面右端のタブから設定します。タブは動画再生中以外も開けますが、シーズン／シリーズ設定は再生中だけ選択できます。サーバー配信方式とTampermonkeyは同時に有効化しないでください。

同期にはHTTPSと[対応API](SYNC_API.md)が必要です。APIサーバー実装と共用同期サービスは含まれていません。

## 今回の追加：v1.12.0

作品一覧・話数一覧のサムネイルに、スキップ対象を示すⓈバッジを追加しました。シリーズ・シーズンでは各話を確認し、カーソルを乗せると全話／一部の対応状況を表示します。詳しくは[変更履歴](CHANGELOG.md)をご覧ください。

更新する場合はJSを置き換え、既存の読込タグの `?v=1.12.0` を更新します。[更新・復旧手順](GUIDE.md#アップデートロールバック)には、Emby本体更新後の再導入方法も記載しています。

## 動作確認と制約

動作確認済みの構成は **Ubuntu / Emby Server 4.10.1.0 / Chrome・Brave** です。サーバー配信方式で、Tampermonkeyを無効にして確認しています。EmbyのAndroid／iOSネイティブアプリは対象外です。

検出結果はEmbyのマーカーやチャプター名に依存します。EDを末尾まで飛ばすと、エンディング後の本編や次回予告を見逃す場合があります。Embyの仕様変更により動作しなくなる可能性もあります。
